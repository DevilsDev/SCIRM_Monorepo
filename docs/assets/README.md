# Assets Directory

This directory contains all images, diagrams, and media files for the SCIRM documentation.

## Organization

- `diagrams/` - Architecture and system diagrams
- `screenshots/` - UI screenshots and examples
- `logos/` - Brand assets and logos
- `icons/` - UI icons and symbols

## Guidelines

- Use relative paths from documentation files: `![Image](../assets/diagrams/example.png)`
- Optimize images for web (compress, appropriate formats)
- Use descriptive filenames
- Include alt text for accessibility
